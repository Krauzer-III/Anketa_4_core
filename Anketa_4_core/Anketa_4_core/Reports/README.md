# Excel-шаблон отчёта Anketa 4

В эту папку необходимо положить бинарный файл **`report.xlsx`**.

Он создан на основе пользовательского шаблона Anketa 3:

- `Компетенции` → `Компетенции (1 год)`;
- дубликат листа → `Компетенции (2 год)`;
- сохранены остальные листы `360° ` (с пробелом в конце),
  `Мотивац. опросник`, `Псих обследование`, `СВОДНЫЙ`;
- на сводном листе ссылки на старое имя компетенций заменены
  на `'Компетенции (1 год)'!`.

Сейчас шаблон передаётся как отдельный бинарный артефакт
`report_anketa4.xlsx` в ответе ChatGPT; скачать его и сохранить по пути
`Anketa_4_core/Anketa_4_core/Reports/report.xlsx`.

`ReportGenerator.Generate` загружает файл из `ContentRoot/Reports/report.xlsx`
при формировании XLSX. Файл автоматически копируется в выходной каталог
проектом (`CopyToOutputDirectory=PreserveNewest`).

## Источник результатов

Контроллер читает только `TestResult.Results` (JSON_ResultModel),
по одному набору на `AccessForTestable.ID`; генератор не обращается
к первичным таблицам 360/Motivation/KT/Comp.

Данные ФИО и должности ещё не представлены в `Testable`,
поэтому отчёт ставит «—» до подключения кадрового справочника.

**Внимание:** старый отчёт по компетенциям использовал нормированный
`LevelNumber`. Для первого года таблицы `Comp_Levels` из Anketa 3
не обнаружены в исходниках; перенос сырых `Ball` в поля уровней запрещён.
Пока `LevelNumber` отсутствует, соответствующие поля остаются
незаполненными. Для второго года перенесены нормы из Anketa 3 при
`MaxBall == 12`.

## Ограничения

Шаблон рассчитан на **не более 100 тестируемых** в одной книге.
Все выбранные назначения должны принадлежать одному `TestPeriod`.
Для больших выгрузок потребуется расширение готовых строк
и формул.
